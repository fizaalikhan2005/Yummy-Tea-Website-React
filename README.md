# 🧋 Yummy Tea (React SPA)

> A modern, component-driven Single Page Application (SPA) for a premium bubble tea brand, built with React and Vite.

## 🚀 Project Overview
This project represents the migration of a static HTML/CSS e-commerce landing page into a fully functional React web application. By utilizing React's component-based architecture, the codebase is highly modular, maintainable, and scalable.

## ✨ Features
- **Component-Driven UI:** Clean, reusable UI elements including dynamic `ProductCard` components.
- **Client-Side Routing:** Instant, reload-free page navigation using `react-router-dom`.
- **Dynamic Props:** Menu items are rendered dynamically by passing data (images, names, prices) via React props.
- **Responsive Layout:** Beautifully styled for both mobile and desktop screens.
- **Modern Tooling:** Lightning-fast development environment powered by Vite.

## 🛠️ Tech Stack
- **Frontend Framework:** React.js
- **Build Tool:** Vite
- **Routing:** React Router v6
- **Styling:** Vanilla CSS
- **Icons:** FontAwesome

## 💻 How to Run Locally

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/fizaalikhan2005/Yummy-Tea-Website-React.git](https://github.com/fizaalikhan2005/Yummy-Tea-Website-React.git)

2. **Navigate to the project directory:**
   ```bash
   cd Yummy-Tea-Website-React

3. **Install the dependencies:**
   ```bash
   npm install

4. **Start the development server:**
   ```bash
   npm run dev

Open http://localhost:5173 in your browser to view the project!
